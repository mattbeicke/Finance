# Matt's Finance App

A brief description of what this app does.

## Features
- Expense tracking
- Balance monitoring

## Tech Stack
- **Language:** Java 26
- **Framework:** JavaFX
- **Build Tool:** Maven
- **Database:** SQLite

## Getting Started
### Prerequisites
- JDK 26 or higher
- Maven 3.9.14+

### Setup
1. Clone the repo: `git clone https://github.com`
2. Build Jarfile: `mvn install`
3. Run: `javaw -jar .\target\Finance-1.0.0.jar` or run the jar any other way
